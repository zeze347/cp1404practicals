# CP1404 Practicals

## About this Repository

My name is Jiaxing Tian. I am an international master's student from China.

In these practical assignments, I learned how to write efficient, clean and maintainable Python code.

During these practicals, I learned several important clean code principles:

- Use meaningful variable and function names.
- Keep functions small and focused on a single responsibility.
- Format and structure the code consistently, including indentation and line length.
- Avoid duplicated code.
